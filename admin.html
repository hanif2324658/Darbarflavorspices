Google Firebase / Cloud Realtime Sync (فوری کلاؤڈ کنکشن) Instant Local Active

جب دکاندار موبائل سے ریٹ یا پروڈکٹ تبدیل کرے تو انٹرنیٹ پر تمام کسٹمرز کو سیکنڈوں میں بغیر ری ڈپلائے کیے تبدیلی دکھانے کے لیے یہاں Google Firebase Realtime Database کا اینڈ پوائنٹ درج کریں۔

💡 فائر بیس کا آسان ترین طریقہ (30 سیکنڈ سیٹ اپ):
1. console.firebase.google.com پر مفت پراجیکٹ بنائیں۔
2. Build > Realtime Database منتخب کریں اور لوکیشن منتخب کر کے Create کریں۔
3. Rules میں جا کر ".read": true, ".write": true سیٹ کر کے Publish کر دیں۔
4. ڈیٹا بیس کا URL کاپی کریں اور آخر میں /darbar_store.json لگا کر نیچے درج فرمائیں!
